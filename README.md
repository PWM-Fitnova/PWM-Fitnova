<h3>
  Descripción del Proyecto
</h3>
<p>Fitnova es una plataforma web diseñada para ayudar a los usuarios a llevar un estilo de vida saludable combinando entrenamiento y nutrición. 
Ofrecemos herramientas personalizadas como recetas fitness, planificación nutricional y seguimiento del progreso físico.</p>
<h3>
  Funcionalidades del Proyecto
</h3>
<ul>
  <li>Funcionalidad 1: Registro y Autenticación de Usuarios.</li>
  <li>Funcionalidad 2: Filtrado de grupos musculares y material necesario.</li>
  <li>Funcionalidad 3: Filtrado de Recetas y alimentación diaria. </li>
  <li>Funcionalidad 4: Almacenamiento del progreso en ejercicios personales. <br>&nbsp;&nbsp;&nbsp;&nbsp;El Usuario podrá guardar un registro de sus series, repeticiones y peso de cada uno de los ejercicios que desee.</li>
  <li>Funcionalidad 5: Gestión del perfil personal<br>&nbsp;&nbsp;&nbsp;&nbsp;El usuario podrá ver y editar los ejercicios que ha guardado previamente. El usuario también podrá visualizar los detalles de las recetas que ha guardado </li>
  <li>Funcionalidad 6: Publicacion de recetas</li>
</ul>
